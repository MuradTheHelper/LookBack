# LookBack App Website

This website is designed to meet App Store requirements for LookBack countdown app submission.

## 📱 LookBack App
Never miss important moments with beautiful countdown timers for personal events, holidays, and global celebrations.

## 🌐 Website Structure

### Main Pages
- **index.html** - Homepage with app overview and features
- **privacy-policy.html** - Comprehensive privacy policy (GDPR/CCPA compliant)
- **terms-of-service.html** - Complete terms of service (legally robust)
- **faq.html** - Frequently asked questions and troubleshooting

### Assets
- **styles.css** - Responsive CSS with dark mode support
- **script.js** - Interactive functionality and analytics tracking

## 🚀 Deployment Instructions

1. **Prepare Images:**
   - Create all screenshots as specified above
   - Optimize images for web (WebP recommended)
   - Add images to `images/` folder

2. **Customize Content:**
   - Update contact email addresses
   - Add your business address
   - Customize app store URL when available
   - Update copyright information

3. **Deploy to Hosting:**
   - Upload all files to your web hosting
   - Configure SSL certificate
   - Test all links and forms
   - Verify mobile responsiveness

4. **Domain Setup:**
   - Point domain to hosting
   - Configure DNS settings
   - Test from multiple devices
